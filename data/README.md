- Shared captures live in the Cloud Storage bucket `gs://<PROJECT_ID>-captures/` (see `docs/CAPTURE_PROTOCOL.md` for folder naming).
- Anyone photographed signs the consent note in `docs/CAPTURE_PROTOCOL.md` first.
